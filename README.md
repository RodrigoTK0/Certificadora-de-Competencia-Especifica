# Sistema de Gerenciamento de Ordens de Serviço - Oficina Mecânica

Este projeto faz parte da **Fase 1** do curso de **Certificadora de Competência Específica (CCE)**. O objetivo é fornecer uma solução moderna e eficiente para pequenas oficinas mecânicas que ainda realizam o controle de serviços de forma manual.

## 🛠️ Tecnologias Utilizadas

- **Frontend**: HTML5, CSS3 (Vanilla com Glassmorphism) e JavaScript (Vanilla).
- **Arquitetura**: Single Page Application (SPA) para uma experiência de usuário fluida.
- **Ícones**: Lucide Icons.
- **Design**: Dark mode premium com foco em usabilidade e estética moderna.

## 🚀 Funcionalidades (Fase 1 - Frontend)

- [x] **Tela de Login**: Interface intuitiva com simulação de autenticação.
- [x] **Dashboard**: Resumo visual de ordens abertas, concluídas e clientes ativos.
- [x] **Gestão de Clientes**: Cadastro e listagem de clientes com busca.
- [x] **Gestão de Veículos**: Controle de frota por cliente (placa, modelo, marca).
- [x] **Ordens de Serviço (O.S.)**:
    - Criação de novas ordens com seleção de cliente e veículo.
    - Listagem centralizada com status (Em Aberto, Em Progresso, Concluído).
    - Cálculo automático de valores (Peças + Mão de Obra).
